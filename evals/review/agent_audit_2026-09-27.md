# 首批 15 条测评草稿审核建议（2026-09-27）

本文件是 Agent 对现有 `annotation_drafts.jsonl` 的**预审意见**，不是人工批准，也不改变 `decisions.jsonl`、`approved_annotations.jsonl` 或 Langfuse 数据集。工程测试只证明被引用的协议边界，不能替代原始自然语言的真实模型回放。

## 评分约定

- 每个案例使用独立合成身份、固定初态和版本化政策资料；多轮案例逐轮执行，并在每轮后记录状态和 Trace。禁止上传真实记忆、密钥或生产会话。
- `must_not` 中的越权写入、旧结果复用、虚构金额、跳过复核属于硬门禁：命中即失败，不能与其他高分平均抵消。
- 状态、记录 ID、revision、结构化查询状态、工具次数等采用程序断言；“靠过道/过道座位”等等价表达和政策解释可用带证据的语义评分，并人工抽查争议项。不以最终回复中的“已记住”代替持久化检查。
- 前置条件没有发生的案例记为 `not_triggered`，运行环境不可用记为 `blocked`，都不计入通过率。脚本化故障注入与真实模型语言评测分开统计。
