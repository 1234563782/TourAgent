## 如何验收

测试使用合成身份与数据，真实外部业务服务不参与。
SDK集成测试保留真实 SDK、LangGraph、模拟模型和内存 span 导出器，禁止 httpx/requests 发送网络请求。
检查最终导出的 span 属性、资源、事件中不含敏感标记，同时检查父子关系、trace一致和结束时间。

| 场景或问题 | 实际结果 |
| --- | --- |
| 关闭观测但系统存在SDK启用变量，会不会加载SDK？ | 不加载、不初始化；原业务配置对象保持不变 |
| 凭据缺失、地址错误、SDK初始化失败怎么办？ | 继续执行业务；固定告警，不泄露模拟秘密 |
| SDK创建、更新、结束span抛错怎么办？ | 不遮盖或重放业务；Web仍正常返回 |
| 提示词、工具参数、输出和异常正文会被采集吗？ | mock边界和真实SDK最终导出检查均未发现测试敏感标记 |
| 两个并发请求的span会混在一起吗？ | 并发屏障测试验证父请求不同，退出后上下文清除 |
| 同一已完成请求重发或读取历史怎么办？ | 原图仅执行一次，只有一个chat追踪 |
| SSE结束但槽位被拒绝，应如何记录？ | 请求completed，槽位提交false；不混为业务成功 |
| 流中抛出异常怎么办？ | error事件，无done；追踪failed，未记录成功提交 |
| 人工确认中断怎么办？ | awaiting_confirmation，不记工具失败 |
| 查询为空或RAG证据不完整怎么办？ | 保留empty/incomplete/insufficient/unavailable等区别，无原始候选或文档内容 |
| 退出时SDK关闭失败怎么办？ | provider仍关闭，重复shutdown不重复执行 |

这些是自动化合成测试，不是本轮真实用户多轮问答；没有生成或宣称真实模型回答。
