问题：

> 请解释2026-09-14适用的差旅制度：住宿费是按每人每天还是每间每晚计算？含税吗？限额是不是固定发放？只讲制度，不核验个人费用。

实际回答包含4.2、4.3、4.5、10.1等来源引用。

结果：通过。耗时11224ms，任务 completed。

### 3. 跨晚平均与例外

问题：

回答摘要：逐晚判断，不跨晚平均冲抵；旺季、会展或安全需要确需超标时存在专项审批路径。
审批须明确人员、事项、期限和额度，只覆盖批准范围；查询不等于获批。

结果：通过。耗时8847ms，任务 completed。

第一项为验收脚本问题：最小实验复现5秒超时后，显式配置90秒断言等待；
没有删除断言，也没有把超时回答当成功。

后续已确认的业务失败模式是：模型选择 answer，却提交了不满足后端互斥约束的字段组合。
工具 JSON Schema 当时没有说明 claims、question、search_query 分别属于哪个动作，
这些约束只存在于服务端 model_validator，模型无法从字段定义充分获知。

修复：补齐工具字段说明和提示中的互斥规则，未使用的字段必须为空。
保留原有严格参数、原文引用、语义复核和保守失败行为，未增加按城市、职级、金额或问句匹配的分支。
增加契约可见性和混合动作拒绝测试，前者修复前失败、修复后通过。

注意：提示及字段说明改善成功率，但不是硬性生成保证；工具调用后的服务端校验仍不可省略。
初期第四问的具体互斥错误码未捕获，不能断言它每次都与第二问同因。
