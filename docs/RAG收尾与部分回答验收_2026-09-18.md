# RAG 收尾与部分回答验收

日期：2026-09-18

## 目标与改动

检索预算用尽或查询重复时，停止检索，使用已收集的同版本来源生成一次有界收尾。
收尾工具契约不允许继续检索；部分回答必须同时有引用结论、未解决部分及核实建议。
引用校验、独立语义复核、来源版本检查和上下文预算仍然保留。

个人住宿仅缺档次时允许列出参考标准，但不能推断个人适用档次。
程序禁止把参考性回答标为完整个人结论；具体限制文字由独立复核检查，
不能仅因“缺少映射依据”被标为 missing_evidence 而不是 applicability_unknown 就拒绝。

部分回答明确缺少政策依据且还有检索额度时，程序按已复核的未解决主题继续检索。
已经由确定性查询识别为个人档次未知的参考回答不需要因此反复检索。
各轮来源有界合并，避免后一次检索丢失前一轮交通等依据。

## 如何验收

- 使用真实 `explain_policy` 函数和模拟模型/来源，覆盖耗尽、重复查询、部分回答、跨轮来源合并、
  禁止收尾再检索、伪造引用、审核拒绝、版本变化、上下文预算及供应商失败。
- 使用实际 LangGraph 流程检查部分答案正常渲染、任务保持 partial，不冒充完整完成。
- 使用本地虚拟环境运行全量离线回归；未开启需要显式授权环境的数据库测试。
- 通过 `scripts/verify_policy_finalization.py` 调用真实政策库与模型，使用合成问题，不写个人会话。
  该脚本本轮关闭 Langfuse 上报，结果与可选模型草稿只保存在 `.verification/policy-finalization/`。

最终命令：

```powershell
$env:TRAVEL_TEST_POSTGRES='0'
.\.venv\Scripts\python.exe -X utf8 -m unittest discover -s tests -q
.\.venv\Scripts\python.exe -m pip check
```

最终结果：842 项，751 通过，91 跳过，零失败；运行 21.534 秒。依赖检查通过。
测试中的 Langfuse 不可用告警来自故障降级用例，不代表真实云端联调通过或失败。

## 真实问题与结果

### 院士赴江西，明确要求列档

问题：我是院士，去江西出差，我的交通和住宿标准分别是什么？
如果无法确定住宿档次，请列出政策标准并说明需要核实什么。

结果：一次检索后返回 partial，列出交通依据、江西三档住宿金额，并说明不能确定个人住宿档次。
针对部分回答与不猜测映射的验证通过。
记录：`.verification/policy-finalization/academician-jiangxi-live.json`。

### 原始综合问法

问题：我是院士，帮我查一下我的出差标准是什么，目的地江西。

初次及仅加强提示词后：只查一次就返回部分回答，没有找回江西住宿附表。
这不满足充分利用剩余检索额度的目标，未按成功计入。

补程序分支后：两次检索，保留交通依据，并找回江西全省住宿参考标准：
部级800、司局级470、其他人员350元/人·天。
明确不能据现有资料把院士对应到某一住宿档次，建议学校财务核实。
该次验证的补检索、部分回答与未知映射处理通过。
记录：`.verification/policy-finalization/original-intent-followup.json`。

但该次交通回答省略了轮船条款中的“不包括旅游船”，独立语义复核仍返回 accept。
因此不能把这一回答认定为完整语义验收通过；限定条件遗漏仍是已观察到的剩余问题。
不能通过把该条款写死到业务代码解决，后续应单独增强条件、例外的覆盖核对并进行独立泛化验收。

### 教授赴北京

问题：我是教授，去北京出差，我的住宿标准是多少？

初次失败：模型已有三档金额及无法确定个人映射的声明，
但分类标签为 missing_evidence，被本地必须为 applicability_unknown 的限制误拦截。
记录：`.verification/policy-finalization/professor-beijing-diagnostic.json`。

修复后：一次检索返回 partial，列出北京部级1100、司局级650、其他人员500元/人·天，
明确不知道教授对应哪档并建议财务核实，引用与独立复核通过。
记录：`.verification/policy-finalization/professor-beijing-fixed.json`。

## 边界与未验证项

- 检索耗尽后模型仍请求 retrieve 的强制收尾分支由确定性回归覆盖；
  本轮真实请求没有自然触发该分支，不声称已完成该分支的真实模型验收。
- 真实请求直接调用政策解释入口，事实与查询类别由验收脚本提供；
  未验收网页操作、槽位识别或完整聊天链路。
- 91 项跳过不算通过；没有重跑所有外部服务与数据库专项测试。
- 首次沙箱请求无法读取政策库，按权限流程获准后重跑成功；未绕过鉴权或改配置。
- 本轮未重启或启动服务，未修改 `.env`、数据库政策、个人会话或依赖。
  已运行的旧服务需要重启后才会加载本轮代码。

结论：检索收尾与部分回答的工程分支已落地，离线回归通过；
真实问法验证了参考标准展示与未知映射处理，但仍有语义限定条件遗漏，不宣称所有回答质量问题已解决。
