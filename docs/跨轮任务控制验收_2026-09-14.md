## 发现并修复

| 发现 | 证据 | 处理 |
| --- | --- | --- |
| 补充事项时旧依赖消失 | 新增测试中 dependencies 从 parent 变为空 | 保留旧依赖并在派发前重新校验 |
| 取消任务被更正改成 blocked | 新增版本变更测试失败 | 取消终态跳过失效传播，新查询使用新 ID |
| 前置取消后仍提示完成它 | 新增取消链路中文断言失败 | 专用前置取消状态和重新安排提示 |
| 共享校验器破坏实验脚本 | 首轮全量 452 项中 12 项报 TypedSubmission 缺字段 | 拆分任务批次校验，生产控制校验不使用静默兼容 |
| 新测试夹具选了同程两种交通 | selection_failed:StopIteration，已有选择门禁正确拒绝 | 将依赖恢复场景明确为机票，不放宽生产选择断言 |
| 浏览器验收总超时 | 首次脚本超过 360 秒且无中间证据 | 补阶段记录，以有界 UI 完成等待替代无界响应收尾等待；缺乏首轮证据，不能认定唯一根因 |
| 否定取消回答抽取失败 | 状态断言通过但实际回答不合格；加质量断言后复现，复核先拒绝 resume、再要求 keep/resume | 统一 schema、抽取、复核的“保持现状”语义；正常委派回应不更改待办 |
| 缺日期的明确继续被降为闲聊 | 真实模型回复追问但原任务尝试次数仍为 1 | 明确控制意图不依赖事实完整度；由执行器检查缺字段，不替换为 other |

上述真实模型失败没有隐去，也没有把失败回答当作通过。修订的是通用协议语义，不包含城市、
固定问句匹配或测试答案分支。最后一次固定七轮通过不代表稳定成功率，也不能保证所有同义表述。
