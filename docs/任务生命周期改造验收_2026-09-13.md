## 改了什么

- 新增 `business_travel/tasks.py`，任务台账复用检查点，不增加数据库表或第二份槽位事实。
- `graph.py` 派发前核对事项版本；同事项同意图复用任务 ID，同批只执行最终修订。
- 槽位提取和独立复核接收 `pending_tasks`，支持跨闲聊保留待补目标。
- 本轮任务可声明前置任务，缺信息、部分结果或失败均不能被视作前置任务已完成。
- 独立任务分别记录完成或失败，单项助手模型异常返回脱敏提示，其他独立任务继续。
- 保存沿用原确认和版本门禁，任务记录待确认及取消状态。
- Web 快照提供白名单任务字段，不暴露工具原始响应；未新增前端任务面板。

- 检查依赖未完成时不调用助手；已完成时才调用。
- 检查非法、自指、向后及重复依赖索引被拒绝。
- 检查供应商失败与助手模型失败不阻塞独立任务，异常原文不泄漏。
- 检查 SQLite 和 PostgreSQL 连接重建后任务状态恢复，不同会话不串读。
- 检查保存中断状态及取消后没有历史行程写入。
- 保留已有鉴权、会话归属、旧确认拒绝和记忆隔离测试。

## 删除与保留

已删除：

- `TripRequest` 类型及无查询范围时默认执行交通的回退，不留同名别名。
- 途牛与 FlyAI 中为旧无范围请求设置的执行分支。
- 图构造函数无调用的 `stop_on_draft`、`stop_after_tools` 参数及其分支。
- 验证脚本、现行测试对旧查询契约的引用，统一改用三个明确契约。

保留：

- 旧事项事实：数据不删除，但查询前必须澄清范围，不再继承旧执行假设。
- SQLite 检查点和本地记忆适配：仍被离线测试、迁移脚本和本地工具实际使用。
- 记忆迁移与旧偏好读取：保护已有数据迁移，不等于保留两套主助手流程。
- 旧 `/api/chat`：当前仍有实际测试和旧 web 线程用途，本批未同时迁移 HTTP 入口。

工作区此前已有的大批旧文件删除和未提交修改保持原样，不将它们冒充本批新增清理。

## 未通过或未覆盖

1. **用户展示仍有英文内部码**：真实结果出现 `unknown`、`insufficient_information`、
   `each_night_requires_individual_verified_quote`，需要统一中文展示和可操作提示。
2. **还不是真实执行流式**：图执行期间页面只有“正在处理”，SSE 仍为执行完成后分段返回。
3. **真实价格、逐晚政策核验信息不足**：本轮验证查询及诚实提示，不宣称得到最终价格或合规结论。
4. **P2 未完全实现**：没有通用任务取消命令；历史阻塞任务不跨轮自动重放，需要用户重新明确请求。
   后续恢复机制必须重新核对意图、版本及写入授权。
5. **真实多事项歧义、批内依赖、供应商故障未做浏览器全覆盖**：当前主要依靠确定性回归，
   仍需更多未见表达的真实模型验收。
6. **P3-P5 尚未完成**：上下文预算、完整统一结果协议、运行幂等与真实流式恢复、长期评测未交付。

因此，本批代码与列出的真实流程通过，不等于所有问题都已解决。
