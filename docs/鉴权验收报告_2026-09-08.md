## 执行方法与结果

1. 现有 `.venv` 安装固定 FastAPI 0.141.1、pwdlib 0.3.1，复用 Uvicorn 0.52.4。
   原有核心依赖未升级；`pip check` 无依赖冲突。
2. 全量 unittest 显式启用真实 PostgreSQL：173 项全部通过，无跳过。
   包含原有 150 项以及新增 15 项离线、8 项真实数据库鉴权测试。
3. 真实测试使用随机 schema 和合成账号，不修改既有偏好、行程或检查点。
4. Playwright 驱动本机 Edge，连接临时真实 FastAPI 和 PostgreSQL；
   1440×900、390×844 截图检查通过，320×640 登录页无横向溢出。
   页面品牌图片正常加载，没有 JavaScript 页面错误。
5. 正式库 `scripts/auth_admin.py init` 执行成功；本地服务启动于
   `http://127.0.0.1:8000`，首页及脚本返回 200，匿名个人记忆返回 401。
   未创建默认或正式账号，未修改真实 `.env`。
6. `git diff --check` 通过，仅有原有 LF/CRLF 提醒。

## 输入、响应与判断

| 验收问题/操作 | 实际响应或结果 | 判断 |
| --- | --- | --- |
| 未登录请求本人信息和记忆 | 401，不返回个人记录 | 通过 |
| 伪造 Cookie | 401 | 通过 |
| 正确账号密码登录 | 200，仅返回 ok；会话写入 HttpOnly Cookie | 通过 |
| 错误密码、不存在账号 | 登录失败，不返回用户记录 | 通过 |
| 密码保存方式 | Argon2id，重复哈希盐不同，可验证正确/错误密码 | 通过 |
| 数据库存储浏览器令牌 | 只保存摘要，不保存原始令牌 | 通过 |
| 重建 AuthStore、浏览器刷新 | 登录会话仍然有效 | 通过 |
| 到期后重放 Cookie | 无有效身份 | 通过 |
| 退出后重放 Cookie | 无有效身份；重复退出成功 | 通过 |
| 重置密码 | 旧会话全部失效，旧密码失败、新密码成功 | 通过 |
| 停用后登录/使用旧会话 | 都被拒绝；启用后可重新登录 | 通过 |
| 相同用户名跨公司 | 两家公司独立账号，跨公司令牌无效 | 通过 |
| 两个用户读取偏好 | 分别返回各自预置的 aisle/window，未串用户 | 通过 |
| 传入别人的 user_id | 登录请求额外字段 422；记忆查询参数 400 | 通过 |
| 跨站/无 Origin 的 POST | 403，未进入登录逻辑 | 通过 |
| 伪造 Host | 400 | 通过 |
| 超过 IP 登录次数 | 跨 AuthStore 实例共享限制，429；窗口到期恢复 | 通过 |
| 账号连续失败 | 暂时锁定，正确密码也不能绕过；到期恢复 | 通过 |
| HTTPS 来源 | Cookie 含 Secure，响应有 HSTS | 通过 |
| 非本机 HTTP 来源配置 | 配置直接拒绝 | 通过 |
| 格式错误或数据库异常 | 固定脱敏响应，不回显密码和连接串 | 通过 |
| 超大请求 | 超过 4096 字节返回 413 | 通过 |
| 网页错误密码后再次登录 | 提示错误并清空密码，正确输入后进入工作台 | 通过 |
| 网页切换历史、刷新、退出 | 空状态准确，退出后记忆 API 返回 401 | 通过 |
| 页面与脚本持有令牌 | document.cookie 无登录令牌，localStorage 为空 | 通过 |

这些是确定性 HTTP、数据库与浏览器行为，不是大模型对话回答。
